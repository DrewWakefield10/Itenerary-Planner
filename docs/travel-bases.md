# Overnight bases and local stops

New trips select El Nido (`el-nido`), Coron (`coron`), or Puerto Princesa (`puerto-princesa`). Their `province: "Palawan"` field groups the picker and supports discovery searches; it is never passed to routing as an extra destination. Each base owns its stops. El Nido reuses the former catalog's stop collection and photograph. Coron uses town on Busuanga, not Coron Island; Puerto Princesa uses the city proper, not a province center or Sabang.

The complete catalog retains `palawan` with `legacyOnly: true`. Request, day, and trip validation still accept it. Loading/importing does not rename the slug or change a traveler's activity coordinates. Legacy catalog generation remains available for existing workflows. New-trip discovery, recommendations, and templates use `selectableDestinations`. An old planner draft or link must be explicitly replaced by a traveler selecting a base before proceeding; there is no automatic base inference.

The existing engine reserves one connection day between requested bases, including bases in the same province. These remain provisional transport and cost allowances, not timetables or bookings. Baguio has central and Leonard Wood Road park clusters within the same base; a cluster never adds a connection day. Local traffic, access, and actual travel times require confirmation.

Fact-specific metadata records reviews on 19 October 2026 for the new data. General Coron sea access is supported by [Department of Tourism](https://app.philippines.travel/interests/coron); Puerto Princesa city transport and Plaza Cuartel's location by [City Tourism](https://citytourism.puertoprincesa.ph/plaza-cuartel/); Baguio park addresses by the [City Government tourist directory](https://infoboard.baguio.gov.ph/tourists-spots). Town reference coordinates were checked against Wikivoyage (El Nido and Coron) and LatLong.net (Puerto Princesa). Baguio park reference coordinates were checked against Wikipedia. These are reference pins, not surveyed entrances or accessible routes.

Secondary/older reference pins for Lualhati Park, Mount Tapyas, and the Puerto Princesa stops remain labeled estimates with their supporting references. Existing El Nido stop pins retain their unverified status. Prices, durations, opening hours where absent, accessibility, and current operator availability are estimates or unverified. A reviewed location never verifies an activity's price, schedule, or generated description. Existing checked dates are preserved.

Validation: `npm test`, `npm run typecheck`, `npm run test:browser`, `npm run build`, and `npm run build:vercel`. The focused travel-base browser check captures desktop and mobile picker screenshots, tests keyboard selection, and restores both new and legacy JSON backups.
